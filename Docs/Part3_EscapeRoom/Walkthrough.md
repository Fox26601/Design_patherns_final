# Escape Room — Walkthrough (Part 3)

## Goal

Escape the locked crimson room by collecting items, combining them, and opening the door.

## Controls

- **Left click** — examine / pick up / interact
- **Inventory** — click a slot, or press **1–6**, then click a target to use the item
- **I** — inspect-all report (Visitor)
- **R** — room report (Visitor)
- Click / press the same slot again to deselect
- **Esc** — pause

## Solution

1. Click the **Rusty Key** on the floor → it goes to inventory.
2. Select **Rusty Key** (slot or key `1`), then click the **Drawer**.
3. Click the revealed **Note** → you learn the code `7391`.
4. Click the **Safe** → enter `7391` → you receive the **Gold Key**.
5. Select **Gold Key**, then click the **Door** → you escape.

Used items leave the slots and appear under **Used:** (they cannot be used again).

## Red herring

The red cube is a decoy. It prints: `This red box does nothing. Keep searching.`
